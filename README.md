# Business Quiz App Suite 📊🎓

A collection of multiple-choice question modules designed for academic courses in business and information systems. This project includes categorized question sets and simple interfaces that allow users to take quizzes, manage content, and support study or classroom instruction.

## 📁 Features

- 🧠 Multiple-choice quizzes for:
  - Principles of Marketing
  - Business Statistics
  - Database Management
  - Business Applications Development
  - Management of Information Systems
- 🎯 Randomized question generation
- 📋 SQLite database support (optional)
- 🖥️ Admin interface for adding/editing questions (planned or in development)
- 🧪 Quiz taker interface with score tracking
- 💾 Persistent data storage and question categorization

## 🛠 Technologies Used

- Python (Tkinter for GUI, SQLite for database)
- Markdown for content formatting
- JSON/CSV for data portability (optional)
- GitHub for version control and collaboration
